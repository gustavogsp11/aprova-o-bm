## 🚀 Como Usar

### 1. Adicionar sua foto

**IMPORTANTE:** Você precisa adicionar uma foto sua na pasta `LP APROVAÇÃO` com o nome `foto-perfil.jpg`

**Recomendações:**
- Formato: JPG ou PNG
- Tamanho ideal: 400x400 pixels (mínimo 200x200)
- A foto será exibida em formato circular
- Use uma foto profissional com boa iluminação

### 2. Abrir a página

Existem duas formas:

**Opção A - Duplo clique:**
- Navegue até a pasta `LP APROVAÇÃO`
- Dê duplo clique no arquivo `index.html`
- A página abrirá no seu navegador padrão

**Opção B - Terminal/PowerShell:**
```powershell
cd "LP APROVAÇÃO"
start index.html
```

### 3. Testar em diferentes dispositivos

- Desktop: Abra normalmente
- Mobile: Use as ferramentas de desenvolvedor (F12) → Device Toolbar

## 🔧 Personalizações Possíveis

Se você quiser fazer ajustes, aqui estão as partes principais:

### Alterar cores:
Abra `style.css` e modifique:
```css
background-color: #000000;  /* Fundo preto */
color: #ffffff;             /* Texto branco */
```

### Alterar o título principal:
Abra `index.html` e modifique a linha:
```html
<h1 class="company-name">GUSTAVO GUEDES SOUZA PINTO</h1>
```

### Alterar a copy:
Abra `index.html` e modifique a seção:
```html
<blockquote class="profile-quote">
    "Seu novo texto aqui..."
</blockquote>
```
